# MVP 验收记录

验收日期：2026-08-29

## 已完成闭环

1. 用户输入文字、链接或截图；
2. 原始内容在 AI 调用前保存到本地；
3. DeepSeek 提取事项、人物、场景、耗时和提醒时间；
4. AI 失败或未配置 Key 时回退到本地规则；
5. 事项进入今日、顺手处理、等待中或稍后；
6. 用户可以完成、延后、转为等待或放弃；
7. 后台调度器检查到期事项并通过 Web Push 提醒；
8. 新输入先与近期事项进行本地相关性筛选，再由 AI 判断新建或补充；
9. 多次补充保留独立原始来源，AI 结论可以追溯到原始文字或截图。
10. 方法、清单和建议作为便笺附到原事项，不进入待办队列；
11. 主动建议经过必要性判断，简单琐事不会被过度扩写。
12. 事项时间可以直接修改或清除，实际提醒触发器同步更新；
13. AI 建议可以删除，或复制到独立笔记本继续查看；笔记副本可独立编辑和删除。

## MVP 边界

- 当前是单用户应用，没有登录系统，只适合本机、家庭网络或受保护的私有环境；
- 外网部署需要 HTTPS，且应先增加身份认证；
- Web Push 需要用户在浏览器点击铃铛并允许通知；
- 后台调度依赖长期运行的 Node.js 服务，不适合会随时休眠的无服务器部署；
- 链接当前会保存并提取 URL 上下文，但不会主动抓取受登录保护的页面内容；
- 习惯、生活关系和个人规则已有数据模型与产品设计，编辑页面留到下一阶段；
- 发送给 DeepSeek 的是当前输入及最多六条本地预筛选的相关事项摘要，不是完整个人数据库。
- 建议当前基于模型知识生成并明确标注“未联网核验”；实时搜索和来源引用尚未接入。

## 试用重点

试用时优先观察：

- 是否能在十秒内完成一次捕获；
- AI 对“谁应该做什么”的判断是否准确；
- 提醒时机是否真的合适；
- 哪些事项经常被延后；
- 哪些固定习惯、人物关系或生活场景最值得优先录入系统。
